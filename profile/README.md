<p align="center">Test Next.js App Router apps with <code>bun test</code>. No browser, no Next.js server.</p>

```sh
bun add -d proofyard
```

Proofyard runs your routes through Next.js's own router, rendering, Flight, Server Actions and caches,
and lets you query the result with Testing Library.
